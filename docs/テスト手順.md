# score-server テスト手順書

各項目を上から順に実行して動作確認する。
コマンドは `score-server/` ディレクトリで実行する前提。

## 共通の準備（環境変数）

```bash
export BASE=http://localhost:8001                # score-server（compose で 8001→8000）
# チームトークンは init_db が発行。DB から取得:
export TOKEN=$(docker compose exec -T db psql -U score -d score -t -A -c "SELECT token FROM teams WHERE name='team1';")
echo "TOKEN=$TOKEN"
```

> `jq` があると結果が見やすい（`brew install jq`）。無くてもそのまま読める。

## 4. 攻撃成功・二重提出テスト（2チーム必要）

team1 が team2 のフラグを奪う流れ。

```bash
# team2 を追加投入（seed を使わず直接投入）
docker compose exec -T db psql -U score -d score -c \
  "INSERT INTO teams(name,ip,token,ctfd_team_id) VALUES ('team2','127.0.0.2','team2token00000',2);"
# team2 のトークンを Redis に載せるため score-server を再起動（起動時に token をキャッシュ）
docker compose restart score-server && sleep 5
# team2 所有のフラグをローテーター経由で投入
docker compose exec -T flagdb mysql -urotator -pRotator1! ctf_flags -e \
  "INSERT INTO flags(round,team,service,flag) VALUES (3,'team2','service-a','FLAG{steal_me}');"
sleep 6
```

| # | 項目 | コマンド | 期待結果 | ✓ |
|---|---|---|---|---|
| 4-1 | team2 フラグを取り込み | `docker compose exec -T db psql -U score -d score -c "SELECT flag,team_id FROM flags WHERE flag='FLAG{steal_me}';"` | team2 の team_id で存在 | ☐ |
| 4-2 | team1 が攻撃成功 | `curl -s -X PUT $BASE/flags/ -H "X-Team-Token: $TOKEN" -H "Content-Type: application/json" -d '["FLAG{steal_me}"]'` | msg に `Flag accepted! Earned 10.0 flag points!` | ☐ |
| 4-3 | 二重提出は拒否 | 同じコマンドをもう一度 | msg に `Flag already stolen` | ☐ |
| 4-4 | stolen_flags 記録 | `docker compose exec -T db psql -U score -d score -c "SELECT * FROM stolen_flags;"` | (flag_id, attacker_id=1) が1行のみ | ☐ |
| 4-5 | 攻撃ポイント反映 | `curl -s $BASE/scoreboard` | team1 の該当サービス `attack_pts:10` / `stolen:1`、team2 `lost:1` | ☐ |
